# FinTech Lending Dashboard

## Project Objective

This project analyzes a synthetic digital lending dataset to identify business and operational insights.

## Dashboard Focus

The dashboard will track:

- Total applications
- Approval rate
- Disbursement rate
- Average processing time
- Partner performance
- Revenue contribution
- Funnel conversion
- Operational bottlenecks

## Key Business Questions

1. Where are applications dropping in the lending funnel?
2. Which partners generate the highest business volume?
3. Which partners have the fastest processing time?
4. What factors may impact approval and disbursement?
5. Where can operations be improved?

## Tools

- Excel
- SQL
- Power BI
- GitHub

## Expected Outcome

Create an interactive business dashboard that converts lending data into actionable product and operations recommendations.

> Note: This portfolio uses synthetic data and does not contain confidential customer or company information.
