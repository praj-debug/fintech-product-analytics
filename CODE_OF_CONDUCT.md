# Code of Conduct

## Our standard

This project is intended to be a professional, constructive, and respectful portfolio space. Everyone participating in issues, pull requests, discussions, or other project activities is expected to:

- Be respectful and professional.
- Give constructive feedback focused on the work, not the person.
- Assume good intent while addressing disagreements directly and calmly.
- Avoid harassment, discrimination, personal attacks, and inappropriate conduct.
- Respect privacy and do not share confidential, personal, customer, employer, partner, or financial information.
- Keep discussions relevant to the project and its analytical or product context.

## Unacceptable behavior

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, deliberate disruption, sharing private information without permission, or any other conduct that would make participation unsafe or unreasonably hostile.

## Scope

This code applies to interactions in this repository, including issues, pull requests, discussions, reviews, and project-related community activity.

## Reporting

If you experience or observe unacceptable behavior, please report it privately through the repository owner's GitHub profile or GitHub's available private reporting mechanisms. Please do not include sensitive personal information in a public issue.

Reports will be reviewed in good faith and handled as appropriate to the circumstances.

## Maintainer responsibility

The repository maintainer will review reported concerns, seek relevant context, and take proportionate action when the code of conduct has been violated. Possible actions include a warning, removal of inappropriate content, temporary restriction of participation, or permanent restriction from the project.

## Attribution

This policy is informed by common open-source community standards and the guidance published by GitHub Open Source Guides.
