# BookNest client

Frontend starter for BookNest, built with React + Vite.

## Run locally
1. Install Node.js 18+.
2. From this directory, run `npm install`.
3. Run `npm run dev`.
4. Open the local URL Vite prints.

## Current prototype
- Responsive storefront landing page
- Seed book catalogue
- Title/author search
- Category filters
- Wishlist toggle (client-side only)
- Shopping bag drawer with quantity controls
- Demo checkout placeholder

## Next
