# Contributing

This portfolio is intentionally kept simple and evidence focused. Changes should make the work easier to understand, reproduce, or review.

## Commit messages

Use a short, specific commit message that explains the change.

Preferred format:

`type: short description`

Common types:

- `feat` - add a new analysis, artifact, or capability
- `docs` - improve documentation or portfolio context
- `fix` - correct an error in analysis, SQL, or documentation
- `refactor` - improve structure without changing the outcome
- `data` - add or update a dataset or data preparation step

Examples:

- `feat: add partner allocation scoring model`
- `feat: add SLA breach hotspot analysis`
- `docs: clarify synthetic data methodology`
- `fix: correct disbursement conversion query`

Keep commits focused. If a change covers unrelated work, split it into separate commits where practical.

## Portfolio standards

- Keep synthetic or anonymized data clearly labelled.
- Do not add confidential customer, employer, partner, or business information.
- Explain the business question before the analysis.
- Link analysis to a decision, recommendation, or operational action.
- Prefer concrete evidence over broad claims.
