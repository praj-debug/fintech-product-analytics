# Data Dictionary

## FinTech Lending Portfolio Dataset

This document explains the fields used in the synthetic lending dataset.

| Field | Description |
|---|---|
| application_id | Unique identifier for each loan application |
| customer_id | Unique identifier for each customer |
| application_date | Date when the application was submitted |
| partner | Partner or acquisition channel generating the application |
| loan_type | Type of lending product |
| requested_amount | Loan amount requested by the customer |
| approved_amount | Loan amount approved |
| application_status | Current status of the application |
| approval_status | Indicates whether the application was approved |
| disbursed | Indicates whether the loan was disbursed |
| disbursed_amount | Amount actually disbursed |
| processing_days | Number of days taken to process the application |
| estimated_revenue | Estimated revenue generated from the application |
| stage | Current stage in the lending funnel |

## Purpose

The dataset is designed for portfolio analysis of:

- Lending funnel performance
- Customer journey
- Partner performance
- Approval and disbursement
- Operational efficiency
- Revenue analysis
- Product improvement opportunities

## Data Privacy

This project uses synthetic portfolio data created for learning and demonstration purposes.

No real customer or confidential company information is included.
