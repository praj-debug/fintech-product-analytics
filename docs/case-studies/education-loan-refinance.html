Problem

A refinance funnel can lose applicants between eligibility, application start, document collection, sanction and disbursement. A single end-to-end conversion rate does not tell the team where to intervene.

Analysis

The example funnel uses a synthetic dataset of 1,000 leads:

Leads: 1,000 → Eligible: 720 → Application started: 540 → Documents submitted: 360 → Sanctioned: 270 → Disbursed: 210

The largest absolute loss is 180 users between eligibility and application start. The weakest stage-to-stage conversion is application start to document submission at 66.7%. These are different signals and should not be treated as the same problem.

Product recommendations

Improve the eligibility handoff

  • Show a personalised next-step checklist.
  • Set clear expectations about time and required documents.
  • Test one prominent application-start action.

Reduce document friction

  • Group documents by borrower or co-applicant.
  • Show upload progress and specific rejection reasons.
  • Allow applicants to save and resume later.

Measurement plan

Primary metrics: eligibility-to-application-start conversion and application-start-to-document-submission conversion.

Guardrails: document rejection rate, time to submit, and support contacts per application.

Data note: All funnel counts and calculated rates on this page are synthetic portfolio examples, not production results. The case study demonstrates the analysis approach and proposed experiments.

What this demonstrates

Connecting funnel data to a specific user friction, a testable product hypothesis and a measurable outcome, rather than stopping at a dashboard.
