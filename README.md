# FinTech Product Analytics

A practical portfolio project focused on fintech product analytics, digital lending operations, customer journeys, and business insights.

## Project Overview

This project demonstrates how product and operations data can be analyzed to identify business opportunities, operational gaps, and customer experience improvements.

## Key Areas

- Product funnel analysis
- Digital lending operations
- Customer journey analysis
- Partner performance
- Business and operational KPIs
- SQL-based analysis
- Product improvement recommendations

## Tools

- Excel
- SQL
- Power BI
- GitHub

## Goal

To demonstrate practical product analytics and problem-solving skills using real-world fintech and lending scenarios.

## Disclaimer

This portfolio uses sample or anonymized data. No confidential company or customer information is included.
