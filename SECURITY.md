# Security Policy

## Scope

This repository is a public portfolio containing synthetic or anonymized datasets and example analyses.

Please do not submit confidential, personal, financial, employer-specific, customer-specific, or security-sensitive information through GitHub Issues or pull requests.

## Reporting a security concern

For a genuine security concern affecting this repository, please use GitHub's private vulnerability reporting features where available rather than posting sensitive details publicly.

For portfolio content corrections or analytical issues, open a GitHub Issue with enough context to reproduce the concern without sharing sensitive information.
